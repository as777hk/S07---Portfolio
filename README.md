# SAMIUN / SIGNAL — Personal Portfolio

Cybersecurity-first creative technologist portfolio for Samiun Islam.

**Brand:** Secure Systems. Thoughtful Experiences.
**Visual direction:** Cybernetic Minimalism — graphite surfaces, signal cyan, precise typography, restrained motion and interactive 3D.

## Stack
- Next.js 16 App Router + React 19 + TypeScript
- Motion for React
- Three.js interactive Signal Core
- Custom CSS design system
- Vercel deployment

## Routes
/ · /security · /work · /work/[slug] · /experiments · /notes · /notes/[slug] · /about · /contact

## Run locally
    npm install
    npm run dev

## Content integrity
Projects are labelled as studies, concepts or explorations where applicable. Security content describes learning interests and responsible practice, not unverified certifications, client work or penetration-testing claims.
